<|det|>title [33, 156, 543, 206]<|/det|>• Interface Design Principles - I
<|det|>text [85, 236, 892, 311]<|/det|>- Anticipation—A WebApp should be designed so that it anticipates the use's next move.
<|det|>text [85, 325, 900, 404]<|/det|>- Communication—The interface should communicate the status of any activity initiated by the user
<|det|>text [85, 415, 842, 493]<|/det|>- Consistency—The use of navigation controls, menus, icons, and aesthetics (e.g., color, shape, layout)
<|det|>text [85, 503, 900, 621]<|/det|>- Controlled autonomy—The interface should facilitate user movement throughout the WebApp, but it should do so in a manner that enforces navigation conventions that have been established for the application.
<|det|>text [85, 631, 872, 786]<|/det|>- Efficiency—The design of the WebApp and its interface should optimize the user's work efficiency, not the efficiency of the Web engineer who designs and builds it or the client-server environment that executes it.

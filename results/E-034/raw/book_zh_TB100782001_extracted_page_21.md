<|det|>text [83, 109, 177, 133]<|/det|>1 直接计算法
<|det|>equation [110, 139, 443, 193]<|/det|>\[
N _ {\text {到(发)}} = \frac {(1 4 4 0 M - \sum t _ {\text {圆}}) (1 - \gamma_ {\text {空}})}{t _ {\text {占到(发)}}} \tag {9.0.2-1}
\]
<|det|>text [56, 197, 443, 304]<|/det|>式中  \( N_{到(发)} \)  ——到达线、到发线、出发线的通过能力（列/d）；
M——扣除本务机车及调车机车走行线后，到达（到发、出发）场可用于办理列车技术作业的线路数（条）；
<|det|>text [95, 310, 418, 338]<|/det|>\(\sum t_{\text{圆}}\) ——各种固定作业占用到发线的总时间（min）；
<|det|>text [95, 344, 443, 399]<|/det|>\( t_{占到(发)} \) ——每办理一次到、发列车作业平均占用线路的时间（min）；
<|det|>text [119, 403, 412, 428]<|/det|>\( \gamma_{空} \) ——到发线的空费系数，可采用0.15~0.20。
<|det|>text [82, 433, 190, 456]<|/det|>2 利用率计算法
<|det|>equation [110, 465, 443, 524]<|/det|>\[
K _ {\text {到(发)}} = \frac {T - \sum t _ {\text {圆}}}{(1 4 4 0 M - \sum t _ {\text {圆}}) (1 - \gamma_ {\text {空}})} \tag {9.0.2-2}
\]
<|det|>text [56, 528, 312, 552]<|/det|>式中  \( K_{到(发)} \)  ——到发线通过能力利用率；
<|det|>text [127, 556, 436, 580]<|/det|>T——每昼夜全部作业占用到发线的总时间（min）。
<|det|>text [82, 584, 197, 607]<|/det|>到发线通过能力为
<|det|>equation [199, 612, 443, 664]<|/det|>\[
N _ {\text {到(发)}} = \frac {n}{K _ {\text {到(发)}} (1 - \gamma_ {\text {空}})} \tag {9.0.2-3}
\]
<|det|>text [56, 664, 320, 687]<|/det|>式中  \( N_{到(发)} \)  ——到发线通过能力(列/d)间
<|det|>text [128, 690, 346, 713]<|/det|>n——列入计算的货物列车数（列）。
<|det|>text [55, 718, 346, 741]<|/det|>9.0.3 编发线的发车能力可采用下列公式计算：
<|det|>equation [102, 747, 443, 800]<|/det|>\[
N _ {\text { 编发 }} = \frac {(1 4 4 0 M - \sum t _ {\text { 回 }}) (1 - \gamma_ {\text { 空 }})}{t _ {\text { 编发 }}} \tag {9.0.3-1}
\]
<|det|>equation [107, 811, 443, 835]<|/det|>\[
t _ {\text { 编发 }} = t _ {\text { 预占 }} + t _ {\text { 分解 }} + t _ {\text { 编占 }} + t _ {\text { 待编 }} + t _ {\text { 编 }} +
\]
<|det|>equation [146, 841, 443, 864]<|/det|>\[
t _ {\text {技}} + t _ {\text {待发}} + t _ {\text {发}} + t _ {\text {换}} \tag {9.0.3-2}
\]
<|det|>text [55, 866, 323, 890]<|/det|>式中  \( N_{编发} \)  ——编发线的发车能力（列/d）；
<|det|>text [113, 894, 268, 917]<|/det|>M——编发线数量（条）；
<|det|>text [573, 81, 897, 113]<|/det|>\(\sum t_{\text{回}}\) ——各种固定作业占用编发线的总时间（min）；
<|det|>text [593, 118, 886, 143]<|/det|>γ空——编发线的空费系数，可采用0.15~0.20；
<|det|>text [587, 150, 883, 175]<|/det|>t编发——一个列车平均占用编发线的时间（min）；
<|det|>text [587, 180, 927, 261]<|/det|>t预占——开始向编发线解体前预先办理进路的时间，即自允许推峰时起至车列推到峰顶时止的时间(min);
<|det|>text [587, 266, 814, 291]<|/det|>t分解——解体一个车列的时间（min）；
<|det|>text [587, 297, 883, 322]<|/det|>\( t_{集占} \) ——集结一个车列占用编发线的时间（min）；
<|det|>text [587, 327, 856, 352]<|/det|>\( t_{待编} \) ——集结终了后的等待编组时间（min）；
<|det|>text [596, 357, 806, 382]<|/det|>\( t_{编} \) ——车列的编组时间（min）；
<|det|>text [596, 388, 855, 413]<|/det|>t—列车出发技术作业占用时间（min）；
<|det|>text [587, 418, 926, 472]<|/det|>t待发——列车待发时间，即自出发技术作业终了至发车时止的时间（min）；
<|det|>text [596, 477, 926, 532]<|/det|>t发——发车时占用编发线时间，即自列车起动时起至列车腾空该线路时止的时间（min）；
<|det|>text [596, 537, 910, 562]<|/det|>t他——摊到每列占用编发线的其他作业时间（min）。

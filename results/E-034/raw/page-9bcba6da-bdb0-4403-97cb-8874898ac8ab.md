<|det|>title [406, 92, 592, 108]<|/det|>1.1.6【添项配凑类型】
<|det|>text [148, 120, 250, 134]<|/det|>▲适用题型：
<|det|>text [146, 147, 461, 162]<|/det|>添项配凑后可以构造利用不等式的题型；
<|det|>text [148, 175, 250, 189]<|/det|>▲方法原理：
<|det|>text [147, 198, 303, 213]<|/det|>常用添项配凑方法：
<|det|>text [157, 221, 620, 301]<|/det|>（1）单变量观察分母： \(\left\{ \begin{array}{l}x + \frac{k}{x - a} = (x - a) + \frac{k}{(x - a)} +a\\ x + \frac{k}{mx - a} = \frac{(mx - a)}{m} +\frac{k}{(mx - a)} +\frac{a}{m} \end{array} \right.\)
<|det|>text [157, 310, 761, 507]<|/det|>(2) 双变量观察分母: \(\left\{ \begin{array}{l} 2a + 3b + \frac{1}{a + b} + \frac{1}{a + 2b} = a + b + \frac{1}{a + b} + a + 2b + \frac{1}{a + 2b} \\ \frac{a}{b} + \frac{b}{a + b} = \frac{a + b - b}{b} + \frac{b}{a + b} = \frac{a + b}{b} + \frac{b}{a + b} - 1 \\ \frac{3b + 2a}{b} + \frac{b}{a + b} = \frac{b + 2b + 2a}{b} + \frac{b}{a + b} = 1 + \frac{2(a + b)}{b} + \frac{b}{a + b} \\ a + \frac{1}{a - b} + \frac{1}{a + b} = a - b + \frac{1}{a - b} + a + b + \frac{1}{a + b} \end{cases}\)
<|det|>text [157, 518, 600, 564]<|/det|>(3）平方添项： \(\frac{a - 3b}{a^2 + 9b^2} = \frac{a - 3b}{(a - 3b)^2 + 6ab} = \frac{1}{a - 3b + \frac{6ab}{a - 3b}}\)
<|det|>text [157, 575, 728, 643]<|/det|>（4）同乘易化简的结构： \(\left\{ \begin{array}{l}a + b = 1 + \frac{1}{a} +\frac{1}{b}\\ \Rightarrow (a + b)^{2} = \left(1 + \frac{1}{a} +\frac{1}{b}\right)(a + b) = (a + b) + 2 + \frac{b}{a} +\frac{a}{b} \end{array} \right.\)
<|det|>text [146, 653, 846, 695]<|/det|>以上只是列举一部分配凑变形的方式，核心在于朝基本不等式方向构造，多观察题干条件，合理配凑，当然还得多练习.

\[
\therefore \triangle A O B \sim \triangle C O D
\]

即  \( \frac{AO}{CO} = \frac{AB}{CD} \)   \( \because AB = 1, CD = 2, AC = 6 \)

\[
\therefore \frac {A O}{C O} = \frac {1}{2} \Rightarrow C O = 2 A O
\]

\[
\because A C = A O + C O = 3 A O \Rightarrow 3 A O = 6, A O = 2
\]

\[
\mathrm{又} \because \frac {S _ {\Delta A O B}}{S _ {\Delta C O D}} = \left(\frac {A B}{C D}\right) ^ {2} = \left(\frac {1}{2}\right) ^ {2} = \frac {1}{4} = \frac {1}{S _ {\Delta C O D}}
\]

\[
\therefore S _ {\Delta C O D} = 4
\]

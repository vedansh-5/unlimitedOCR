<|det|>title [102, 108, 363, 124]<|/det|>C.3 本标准市电可靠性指标公式
<|det|>text [138, 139, 393, 155]<|/det|>市电不可用度指标见公式（C.1）：
<|det|>equation [241, 160, 882, 194]<|/det|>\[
\text { 市电不可用度 } = \frac {\text { 市电停电时间 }}{\text { 统计期时间 }} = 1 - \text { 市电供电可靠率 } \tag {C.1}
\]
<|det|>text [138, 204, 411, 220]<|/det|>平均年停电时间指标见公式（C.2）：
<|det|>equation [289, 226, 882, 242]<|/det|>\[
\text { 平均年停电时间 } = \text { 市电不可用度 } \times 3 6 5 \times 2 4 \tag {C.2}
\]
<|det|>text [138, 251, 411, 267]<|/det|>平均年停电次数指标见公式（C.3）：
<|det|>equation [246, 273, 882, 290]<|/det|>\[
\text { 平均年停电次数 } = \text { 市电在一年统计期内平均停电次数 } \tag {C.3}
\]

<|det|>title [72, 109, 581, 193]<|/det|>System of linear equations
<|det|>text [71, 272, 915, 328]<|/det|>A collection of one or more equations involving the same variables.
<|det|>text [74, 348, 188, 402]<|/det|>Example:
<|det|>text [78, 419, 747, 552]<|/det|>The system of linear equations \(\left\{ \begin{array}{l} 2x_{1} + 3x_{2} + 4x_{3} = 5 \\ 5x_{3} + 6x_{4} = 7 \end{array} \right.\)
<|det|>text [80, 562, 686, 690]<|/det|>can be rewritten as \(\left\{ \begin{array}{l} 2x_{1} + 3x_{2} + 4x_{3} + 0x_{4} = 5 \\ 0x_{1} + 0x_{2} + 5x_{3} + 6x_{4} = 7 \end{array} \right.\)
<|det|>text [72, 710, 934, 767]<|/det|>Hence it is a system of equations involving the variables \( x_{1}, x_{2}, x_{3}, x_{4} \).

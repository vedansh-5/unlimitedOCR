<|det|>title [148, 221, 250, 236]<|/det|>▲方法原理：
<|det|>text [147, 243, 649, 259]<|/det|>1. 如果可以直接看出或者简单尝试可知系数关系的，则直接处理
<|det|>text [148, 267, 647, 300]<|/det|>比如： \(x > 0,y > 0,x + 2y = 1\) ，则 \(\frac{1}{4x + 3} +\frac{1}{2y + 1}\) 的最小值为
<|det|>text [148, 310, 666, 430]<|/det|>变形： \(\left\{ \begin{array}{l}x + 2y = \frac{1}{4} (4x + 3) + (2y + 1) - \frac{7}{4} = 1\Rightarrow (4x + 3) + 4(2y + 5) = 11\\ \frac{1}{4x + 3} +\frac{1}{2y + 5} = \frac{1}{11}\Big(\frac{1}{4x + 3} +\frac{1}{2y + 5}\Big)\Big[(4x + 3) + 4(2y + 5)\Big]\\ \text{此时建议结合换元处理结构更简单}\left\{ \begin{array}{l}4x + 3 = m\\ 2y + 1 = n \end{array} \right. \end{array} \right.\)
<|det|>title [146, 441, 479, 456]<|/det|>2. 不易看出系数关系的，则待定系数处理：
<|det|>text [147, 464, 657, 497]<|/det|>比如： \(x > 0,y > 0,3x + y = 1\) ，则 \(\frac{1}{5x + y} +\frac{1}{5x + 3y}\) 的最小值为
<|det|>text [148, 508, 692, 680]<|/det|>变形： \(\left\{ \begin{array}{l}3x + y = m(5x + y) + n(5x + 3y)\Rightarrow \left\{ \begin{array}{l}5m + 5n = 3\\ m + 3n = 1 \end{array} \right.\Rightarrow \left\{ \begin{array}{l}m = \frac{2}{5}\\ n = \frac{1}{5} \end{array} \right.\\ \Rightarrow \frac{1}{5x + y} +\frac{1}{5x + 3y} = \left(\frac{1}{5x + y} +\frac{1}{5x + 3y}\right)\left[\frac{2}{5} (5x + y) + \frac{1}{5} (5x + 3y)\right]\\ \end{array} \right.\)
<|det|>text [148, 640, 570, 680]<|/det|>此时建议结合换元处理结构更简单 \(\left\{ \begin{array}{l}5x + y = m\\ 5x + 3y = n \end{array} \right.\)

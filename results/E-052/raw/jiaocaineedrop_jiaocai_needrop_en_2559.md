<|det|>text [113, 109, 893, 125]<|/det|>正四面体 \(ABCD\) 中，\(AB = \sqrt{2}\)，图中点 \(O\) 为外接球的球心，半径为 \(R = OA = OB\)，\(O_1\) 为 \(\triangle BCD\) 的外心，
<|det|>text [114, 127, 577, 169]<|/det|>所以 \(O_{1}B = \frac{1}{2}\times \frac{\sqrt{2}}{\frac{\sqrt{3}}{2}} = \frac{\sqrt{2}}{\sqrt{3}} = \frac{\sqrt{6}}{3}\) 由于 \(O_{1}B^{2} + OO_{1}^{2} = OB^{2}\)
<|det|>text [113, 171, 714, 232]<|/det|>又因为 \(O_{1}A = \sqrt{(\sqrt{2})^{2} - \left(\frac{\sqrt{6}}{3}\right)^{2}} = \frac{2\sqrt{3}}{3}\) 所以 \(\left(\frac{\sqrt{6}}{3}\right)^2 +\left(\frac{2\sqrt{3}}{3} -R\right)^2 = R^2\) 解得\(R = \frac{\sqrt{3}}{2},\)

<|det|>equation [113, 464, 384, 492]<|/det|>\[

<|det|>equation [113, 562, 435, 590]<|/det|>\[
N Q = N S = \frac {\sqrt {6}}{3}, B Q = Q S = A P = \frac {2 \sqrt {2}}{3},
\]
<|det|>text [114, 592, 601, 620]<|/det|>则 \(\triangle NQS\) 的周长为 \(\frac{\sqrt{6}}{3} +\frac{\sqrt{6}}{3} +\frac{2\sqrt{2}}{3} = \frac{2\sqrt{6} + 2\sqrt{2}}{3}\) 故 \(D\) 正确.
